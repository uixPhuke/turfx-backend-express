# UPI and QR checkout — 21 November 2026

## Implementation

PLAYZA uses server-created Razorpay orders and Standard Checkout for payment selection. INR checkout highlights UPI, while keeping other enabled methods available. Live UPI configuration allows Intent and QR flows. Test mode leaves Razorpay's UPI simulator unrestricted because real app switching and QR require live validation. Non-INR orders do not request a UPI block.

The payment screen names UPI apps, UPI QR and cards/netbanking, and explains that available methods depend on the currency, device and provider. The payment QR is generated by Razorpay inside checkout; the PLAYZA booking ticket QR is a separate check-in credential. No static merchant QR, manual UPI transfer or unverified payment-success button was introduced.

Expo iOS Info.plist declares `tez`, `phonepe` and `paytmmp`, following the installed react-native-razorpay SDK requirements. This native configuration needs a new installed build; Metro/web export cannot validate iOS app discovery. Payment amount, currency and gateway order ID come from the existing backend; confirmation still requires server signature/provider verification.
